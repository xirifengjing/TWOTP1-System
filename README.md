# TWOTP1 Virtual Base System V1.0

## Basic Information
- **Software Name**: TWOTP1 Virtual Base System V1.0
- **Developer**: Ji Wang
- **Version**: V1.0
- **Development Tool**: Scratch
- **Completion Date**: November 8, 2026
- **Software Type**: Lightweight innovative virtual runtime system

## Core Innovative Features
This software is the first virtual machine-class innovative program on the internet, completely different from traditional conventional virtual machine products:
1. No need for users to manually install any system images; it comes with a natively designed virtual runtime environment built entirely from scratch, and does not belong to any existing operating system branch system
2. Full device compatibility: it can run directly as long as the Scratch runtime environment is supported, with no underlying hardware adaptation threshold
3. Built-in automatic restore mechanism on reboot: all temporary runtime data is automatically cleared after the program is closed and restarted, only retaining content actively saved by the user into the built-in file system
4. The overall technical route is an exclusive innovative direction with no publicly available reference implementations of the same kind

## Functional Module Description
### 1. Virtual Runtime Core Layer
A completely independently developed lightweight virtual scheduling kernel, responsible for the allocation and scheduling of all virtual resources within the program. It does not rely on the virtualization underlying interfaces of the host system, achieving a completely isolated independent running space.

### 2. Persistent File System
An independently designed lightweight file storage module that only persistently retains files actively imported by users. It is not affected by the program's automatic restore mechanism on restart, ensuring that user-specified data will not be lost.

### 3. Automatic Restore Engine
When the program starts, it automatically resets all runtime temporary data and restores the virtual environment to its initial clean state, avoiding security risks and redundant occupation caused by residual historical operations.

## Usage Instructions
1. Open the program file directly in an environment that supports HTML5 or above to start
2. The virtual environment will be initialized automatically on first launch, no additional configuration required
3. Content saved to the file system during use can be normally read and used after restarting the program
4. All operation records outside the file system will be automatically and completely cleared upon restart
