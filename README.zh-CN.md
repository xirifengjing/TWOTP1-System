# TWOTP1 虚拟基层系统 V1.0 软件说明文档

## 基本信息

- **软件名称**：TWOTP1 虚拟基层系统 V1.0
- **开发作者**：王骥
- **版本号**：V1.0
- **开发工具**：Scratch
- **创作完成日期**：2026 年 11 月 8 日
- **软件类型**：轻量创新型虚拟运行系统

## 核心创新特性

本软件为全网首创的虚拟机类创新程序，完全区别于传统常规虚拟机产品：

1. 无需用户手动安装任何系统镜像，内置完全自主设计的原生虚拟运行环境，不属于任何现有操作系统分支体系
2. 全设备兼容运行，只要支持 Scratch 运行环境即可直接启动，无底层硬件适配门槛
3. 自带重启自动还原机制，程序关闭重启后所有临时运行数据自动清空，仅保留用户主动存入内置文件系统的内容
4. 整体技术路线为独家创新方向，无同类公开参考实现方案

## 功能模块说明

### 1. 虚拟运行核心层

完全独立开发的轻量虚拟调度内核，负责程序内所有虚拟资源的分配与调度，无需依赖宿主系统的虚拟化底层接口，实现完全隔离的独立运行空间。

### 2. 持久化文件系统

独立设计的轻量化文件存储模块，仅对用户主动导入的文件进行持久化留存，不受程序重启自动还原机制影响，保障用户指定数据不会丢失。

### 3. 自动还原引擎

程序启动时自动重置所有运行态临时数据，将虚拟环境恢复到初始干净状态，避免历史操作残留带来的安全风险与冗余占用。

## 运行说明

1. 直接在支持 HTML5 及以上版本的环境中打开程序文件即可启动
2. 首次启动将自动完成虚拟环境初始化，无需额外配置
3. 使用过程中存入文件系统的内容，重启程序后可正常读取使用
4. 所有非文件系统内的操作记录，重启后将自动完全清除
