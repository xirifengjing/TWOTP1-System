## 项目简介

TWOTP1（Virtual Base System）是一款轻量创新型虚拟运行系统，无需用户额外安装任何系统镜像，内置完全自主设计的原生虚拟运行环境，只要设备能运行现代浏览器即可开箱即用。

系统搭载自动还原引擎：每次关闭重启后，所有临时运行数据自动清空，仅保留用户主动存入持久化文件系统的内容，兼顾使用灵活性与环境纯净度，无残留、无垃圾，同时保障用户主动保存的文件不丢失。

## 核心特性

- 🚀 **单文件无依赖**：基于 Scratch 图形化开发，经 TurboWarp Packager 打包为独立 HTML 文件，任意现代浏览器双击即可运行，无需安装任何软件或运行时
- 💾 **双层存储架构**：隔离临时运行环境与持久化用户文件系统，重启不丢失主动保存的个人文件
- 🔄 **自动还原机制**：重启自动清空临时运行数据，避免系统环境污染，始终保持初始流畅状态
- 🖥️ **全平台兼容**：支持 Windows、macOS、Linux 电脑，以及平板、手机等移动设备，只要有浏览器即可运行

## 版本更新日志

### 🆕 V1.1 —— 最新稳定版（2026-11-09）

本次更新聚焦系统稳定性与功能完善，更新内容如下：

1. **更新内置浏览器模块**
   优化了内置浏览器的运行兼容性与页面加载表现，修复部分环境下页面显示异常、功能无响应的问题，提升跨设备运行稳定性。

2. **更新致命错误绿屏界面**
   重构了系统发生不可恢复的致命错误时的全屏提示界面，异常状态辨识度更高。
   > 📝 设计说明：
   > - 绿屏选用绿色作为背景主色，是因为**绿色是作者的幸运色**，同时在各类显示环境下都具备较高辨识度，便于快速识别系统异常状态
   > - 错误提示中的哭脸选用**微软系统经典 `:(` 字符样式**，是为了避免自定义表情图标在不同设备、不同编码环境下出现字符错位、渲染异常的问题

3. **更新虚拟机状态页面**
   升级了虚拟机运行状态展示页面，优化信息布局，可直观查看内存占用、运行时长、存储状态、自动还原状态等虚拟机核心参数。

4. **更新系统重启功能**
   优化了系统重启的完整执行流程，确保临时数据完整清理、持久化文件安全保留，解决部分场景下重启失败、还原不彻底的问题，重启响应速度与执行稳定性同步提升。

## 使用方法

1. 在仓库 Release 或代码目录中下载 `TWOTP1 虚拟基层系统 程序.html` 文件到本地
2. 使用任意现代浏览器（推荐 Chrome/Edge 100+、Firefox 99+、Safari 15+）直接打开 HTML 文件即可运行系统，无需安装
3. 使用提示：
   - 运行过程中产生的临时缓存、应用数据会在重启后自动清除
   - 如需保留个人文件，请将文件存入系统内的「持久化文件系统」目录，重启后不会丢失
